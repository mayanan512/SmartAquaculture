# 智渔云 —— 核心服务接口与字段约定

## 1. 统一枚举常量 (`config/settings.py`)
- **数据来源 (`source_type`)**：`SIMULATED`（模拟数据）、`MANUAL`（人工录入）、`SENSOR`（传感器上报）
- **告警状态 (`alert_records.status`)**：`NEW`（待确认）、`ACKNOWLEDGED`（处理中）、`RESOLVED`（已解决）、`CLOSED`（已关闭）
- **批次状态 (`culture_batches.status`)**：`ACTIVE`（在养中）、`COMPLETED`（已出塘结束）、`PLANNED`（计划放养）

## 2. 统一业务计算口径 (`services/production_service.py`)
- **当前存活数量**：`初始放养数量 - 累计死亡数量 - 累计已出塘数量`
- **当前估算存量 (kg)**：`当前存活数量 × 最近一次有效抽样平均单体重量 (kg)`
- **累计出塘产量 (kg)**：`周期内有效出塘记录的总重量之和`
- **饲料成本 (元)**：`各条投喂记录的 (投喂重量 × 当时饲料单价) 求和`
- **设备在线率 (%)**：`统计时点 ONLINE 设备数 ÷ 纳入统计设备总数 × 100%`
