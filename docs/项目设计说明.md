# 智渔云 —— 项目设计说明与智慧城市赛题契合方案 (`v0.2.0`)

## 一、项目定位与智慧城市大赛契合度设计
本项目面向**中国研究生智慧城市技术与创意设计大赛（自由赛道）**，聚焦智慧城市框架下的三大核心场景：
1. **城市“菜篮子”生鲜稳产保供与全链路溯源**：通过养殖批次、放养苗种、日常投喂、动保投入与出塘流向的全流程数字化建档，为城市农贸与商超冷链提供可核验的水产品数字身份。
2. **都市圈生态循环水养殖与尾水零直排治理**：将“C区生态尾水监测池”纳入园区数字孪生核心监控点位，实时追踪氨氮、pH 与溶解氧变化，防止养殖尾水引发城市近郊水体富营养化。
3. **轻量化数字孪生与边缘-云协同 AI 决策**：采用 `Python 3.11 + Streamlit + SQLite + Plotly 3D + Scikit-learn + 大模型 API` 技术栈，既支持单机免配置快速部署，又支持 3D 立体园区水深剖面态势展示与大模型诊断降级闭环。

## 二、五层架构职责边界
- **页面交互层 (`pages/`)**：包含 9 大业务页面，仅负责接收用户输入、调用 `services/` 并渲染结果。
- **公共组件层 (`components/`)**：提供统一深蓝/青蓝数字孪生 CSS 主题、顶部模式徽章、指标卡及 2D/3D Plotly 图表。
- **业务服务层 (`services/`)**：统一实现存活数、估算存量、成活率、饲料成本、设备在线率计算公式及告警生命周期流转。
- **算法与模型层 (`algorithms/`)**：提供单指标规则比对、时间序列线性趋势斜率计算及 `IsolationForest` 多维无监督异常检测。
- **数据访问与持久层 (`repositories/` & `database/`)**：管理 20 张 SQLite 核心表结构、外键约束、幂等初始化与事务控制。
