# 智渔云 —— 数据库设计规范 (`database/schema.sql`)

## 1. 核心数据表清单（共 20 张表）
| 序号 | 表名 | 主键 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | `aquaculture_farms` | `farm_id` | 养殖场档案 |
| 2 | `aquaculture_areas` | `area_id` | 养殖区域档案 |
| 3 | `fishponds` | `pond_id` | 养殖池档案及园区大屏点位坐标 |
| 4 | `species` | `species_id` | 养殖品种及适宜水质阈值范围 |
| 5 | `culture_batches` | `batch_id` | 养殖批次档案 |
| 6 | `water_quality_records` | `record_id` | 水质监测记录（允许单指标 NULL 缺失） |
| 7 | `alert_rules` | `rule_id` | 阈值预警规则配置 |
| 8 | `alert_records` | `alert_id` | 告警主记录 |
| 9 | `alert_process_records` | `process_id` | 告警确认、处置、复测与关闭历史记录 |
| 10 | `equipment` | `equipment_id` | 传感器与增氧/水泵/投饵设备档案 |
| 11 | `equipment_status_records` | `status_record_id` | 设备在线/离线/故障状态变更历史 |
| 12 | `stocking_records` | `stocking_id` | 苗种放养记录 |
| 13 | `feeding_records` | `feeding_id` | 日常投喂记录（含当时饲料单价） |
| 14 | `growth_records` | `growth_id` | 生长抽样测量记录 |
| 15 | `mortality_records` | `mortality_id` | 死亡损耗与无害化处理记录 |
| 16 | `harvest_records` | `harvest_id` | 出塘销售记录 |
| 17 | `cost_records` | `cost_id` | 苗种、电费、动保药品等成本记录 |
| 18 | `ai_analysis_records` | `analysis_id` | AI 辅助诊断输入摘要与输出建议记录 |
| 19 | `system_settings` | `setting_id` | 系统运行模式与全局参数设置 |
| 20 | `operation_logs` | `log_id` | 关键业务操作审计日志 |
